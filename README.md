# TaxiProfit

TaxiProfit - мобильное веб-приложение для водителей такси, которые работают через Bolt, Uklon, InDrive и другие агрегаторы. Приложение помогает вести смены, фиксировать выручку и расходы, отслеживать пробег и видеть, насколько водитель движется к недельной финансовой цели.

Текущая версия собрана как статическое веб-приложение и подготовлена для использования как Telegram Mini App.

Публичная версия:

```text
https://yuriy-vitalievich.github.io/TaxiProfit/
```

## Цель Приложения

Приложение должно быстро отвечать на четыре главных вопроса водителя:

- Сколько я заработал сегодня?
- Сегодня лучше или хуже, чем вчера?
- Сколько осталось до недельной цели?
- Какие дни и часы реально приносят деньги?

Главная страница сфокусирована на мотивации и прогрессе по неделе, а страница статистики хранит более подробную аналитику.

## Что Уже Есть

- Интерфейс, подготовленный под Telegram Mini App.
- Боковое меню с основными разделами, вторичными страницами и блоком пользователя.
- Главная страница с заработком за сегодня, разницей со вчера, недельной целью и прогнозом.
- Страница статистики с фильтрами: день, неделя, месяц, год, быстрые периоды и произвольный диапазон.
- Сценарий старта смены:
  - выбор платформы;
  - ввод текущего пробега авто;
  - запуск активной смены с точной датой и временем;
  - завершение смены с вводом километров по заказам, финального пробега, количества заказов, выручки, расходов и заметки;
  - отмена активной смены, если она была запущена ошибочно.
- Логика пробега:
  - `km` - километры по заказам/агрегатору;
  - `odometerStart` и `odometerEnd` - реальный пробег авто;
  - `totalKm = odometerEnd - odometerStart`;
  - `extraKm = totalKm - km`.
- Ручное добавление смен и расходов.
- Редактирование и удаление смен/расходов из интерфейса.
- Supabase Auth, персональный профиль водителя и привязка данных к `user_id`.
- Сохранение Telegram `user.id` в профиле для будущей мультипользовательской логики.
- Хранение данных в Supabase и realtime-синхронизация между устройствами одного пользователя.
- Импорт CSV для смен и расходов.
- Основа heatmap заработка по реальным временным сегментам смены.

## Страницы

### Главная

Мотивационный экран:

- заработано сегодня;
- разница со вчера в гривнах;
- чистая прибыль сегодня;
- сколько осталось до недельной цели;
- прогресс недельного плана;
- прогноз по неделе;
- базовые показатели эффективности.

### Статистика

Аналитический dashboard:

- чистая прибыль за выбранный период;
- график дохода;
- количество смен;
- пробег;
- заказы;
- средняя выручка, расходы, прибыль, стоимость заказа и стоимость километра;
- структура расходов;
- календарь рабочих и выходных дней;
- последние смены.

### Начать Смену

Основной рабочий сценарий водителя:

1. Выбрать платформу.
2. Ввести текущий пробег авто.
3. Начать смену.
4. Приложение сохраняет точную дату и время старта.
5. Завершить смену.
6. Ввести финальный пробег, километры по заказам, количество заказов, выручку, расходы и комментарий.

Это позволяет считать не только километры по агрегатору, но и пустой пробег между заказами и точками посадки.

### Данные

Ручной ввод и обслуживание данных:

- добавить или отредактировать смену;
- добавить или отредактировать расход;
- увидеть статус Supabase-синхронизации.

### История

Работа с сохраненными данными:

- импорт CSV;
- просмотр записей смен и расходов;
- очистка данных.

### Кабинет

Профиль водителя:

- статус Supabase Auth;
- Telegram ID;
- Supabase user ID;
- email magic link вход;
- имя водителя;
- город;
- автомобиль и номер;
- основная платформа;
- телефон;
- недельная цель.

## Хранение Данных

Основное облачное хранилище TaxiProfit сейчас - Supabase.

Таблицы:

- `profiles` - профиль водителя и Telegram ID;
- `shifts` - смены;
- `expenses` - расходы;
- `settings` - персональные настройки dashboard.

Приложение также использует `localStorage` как fallback и для хранения активной смены.

Данные привязываются к Supabase `auth.uid()` через поле `user_id`. Telegram `user.id` сохраняется в `profiles.telegram_id` и нужен для будущей логики аккаунтов Telegram Mini App.

Подробнее: [SUPABASE_SETUP.md](SUPABASE_SETUP.md).

## Локальный Запуск

Это статическое приложение. Его можно открыть напрямую через `index.html`, но для тестирования лучше запускать локальный сервер:

```bash
python3 -m http.server 4183
```

Открыть:

```text
http://127.0.0.1:4183/index.html
```

Базовые проверки:

```bash
node --check app.js
git diff --check
```
