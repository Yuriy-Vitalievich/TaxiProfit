# Changelog

## v0.6.0 - Mobile App Foundation

### Добавлено

- PWA manifest для установки TaxiProfit на главный экран телефона.
- Service worker для кеширования app shell и более стабильного запуска.
- Иконка приложения в стиле TaxiProfit.
- Базовая Capacitor-конфигурация для будущей сборки Android/iOS приложения.
- Документация `MOBILE_APP_SETUP.md` с вариантами установки и сборки.

## v0.5.1 - Telegram ID Login

### Улучшено

- Убран видимый экран авторизации: в Telegram профиль подключается автоматически.
- Onboarding показывается только один раз, если у Telegram ID еще нет завершенного профиля.
- Новые устройства и Telegram Desktop ищут существующий профиль и данные по `telegram_id`.
- Supabase-политики обновлены так, чтобы данные одного Telegram пользователя были доступны с разных устройств.

## v0.5.0 - Simplified Auth Flow

### Улучшено

- Первый запуск теперь начинается с простого входа водителя.
- После входа сразу открывается onboarding для создания профиля авто и рабочих агрегаторов.
- Кабинет очищен от технических деталей Supabase/Telegram и оставлен как понятный профиль водителя.
- Данные продолжают привязываться к конкретному пользователю через Supabase Auth и Telegram user ID.

## v0.4.0 - Driver Onboarding

### Добавлено

- Первый запуск приложения теперь открывает onboarding/регистрацию водителя.
- Шаг выбора типа авто: собственное, аренда, авто агрегатора/парка.
- Шаг данных авто со списками марок, моделей и годов.
- Ручной ввод оставлен только для среднего расхода топлива и текущего пробега.
- Шаг аренды показывается только для арендованного авто или авто парка.
- День оплаты аренды выбирается из списка.
- Мультивыбор агрегаторов: Bolt, Uklon, InDrive, Uber, другое.
- Новые поля профиля в Supabase для авто, аренды, агрегаторов и статуса завершения onboarding.

## v0.3.0 - Auth And Driver Profile

### Добавлено

- Supabase Auth для персональной синхронизации данных.
- Таблица `profiles` для кабинета водителя.
- Привязка `shifts`, `expenses` и `settings` к `user_id`.
- Сохранение Telegram `user.id`, username, имени и аватара в профиле.
- Полноценный кабинет водителя: статус входа, email magic link, город, авто, номер, телефон, основная платформа и недельная цель.
- RLS-политики: пользователь видит и меняет только свои строки.

### Улучшено

- Supabase setup-документация обновлена под Auth, профили и миграцию старых данных.
- Realtime теперь подписывается только на строки текущего пользователя.

## v0.2.0 - Home, Shift Flow, Telegram Polish

### Добавлено

- Отдельная страница `Главная` с мотивационным блоком: заработок сегодня, разница со вчера в гривнах, недельная цель и прогноз.
- Страница `Начать смену` с активной сменой, таймером, точным временем старта и финиша.
- Ввод одометра в начале и конце смены.
- Расчет полного пробега и пустого пробега:
  - `totalKm = odometerEnd - odometerStart`;
  - `extraKm = totalKm - km`.
- Возможность отменить активную смену без сохранения данных.
- Новая боковая навигация с основными разделами, вторичными пунктами и блоком пользователя.
- Страница-заглушка `Кабинет`.

### Улучшено

- Страница `Статистика` возвращена к исходной логике с чистой прибылью и аналитикой за выбранный период.
- Heatmap теперь распределяет доход по реальным часовым сегментам смены, а не только по часу старта.
- Telegram Mini App получил фиксированный viewport, защиту от overscroll и корректные отступы под системные кнопки.
- Боковое меню визуально приведено к стилю TaxiProfit: glassmorphism, neon green accents, линейные SVG-иконки.

## v0.1.0 - Telegram Mini App MVP

Первый рабочий релиз TaxiProfit как веб-приложения и основы для Telegram Mini App.

### Добавлено

- Supabase-хранилище для смен, расходов и настроек.
- Realtime-синхронизация данных между устройствами.
- Ручной ввод смен и расходов.
- Редактирование и удаление смен/расходов из интерфейса.
- Импорт CSV для синхронизации с таблицами.
- Функциональные периоды: день, неделя, месяц, год, сегодня, вчера, прошлые периоды и произвольный диапазон.
- Календарь рабочих и выходных дней.
- Месячная цель и прогресс.
- Подготовка Telegram Mini App: Telegram WebApp SDK, тема Telegram, viewport, native Back Button.

### Улучшено

- Мобильная версия dashboard и формы данных.
- Навигация периода выровнена по центру между стрелками.
- Карточки календаря больше не ломают статус `Раб.` / `Вых.`.
- Форма смены упрощена до реального сценария после работы: время, платформа, выручка, километраж.

### Убрано

- Демо-кнопка и автоподстановка фейковых данных.
- Расходы из формы смены: теперь они ведутся только в отдельном блоке расходов.
